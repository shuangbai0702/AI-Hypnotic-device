# DSH 会话编辑器

安装后，在 DSH 网页会话右侧的 **+ → 编辑器** 中操作。

- **有效上下文**：搜索并编辑保留的用户消息、助手回复，保存后同时更新上下文与左侧历史；局部同步，无需整页刷新，保留草稿。备份位于 DSH_HOME/backups/physical-sync。
- **记忆工作台**：选择连续的纯文本记忆区间起草局部摘要，查看成员与估算用量，核对候选修改前后后逐项应用或拒绝。支持工具输出首尾裁剪、历史原件检索、按需补回正文，以及已应用候选的正文/思考/摘要字段恢复。
- **生效摘要**：直接编辑摘要正文，保持原有压缩事务和命令关联；连续保存不会新建压缩事务。已经压缩的旧原文只读，生效摘要仍可编辑。
- **移出上下文**：整条消息（含思考）退出后续模型上下文，原始聊天记录仍保留。
- **原始事件**：查看原始日志；“刷新”重新读取当前视图。
- **覆盖关系**：区分当前有效、摘要替代、其他消息替换、手动移出。展开历史原文、查看替代链，并跳转到当前有效摘要或消息编辑。按官方 foldSurface 的实际成员判定，支持多代摘要，不按时间或编号范围猜测。
- **左侧聊天颜色**：灰色“整条已被摘要替代”、绿色“整条未被摘要覆盖”、蓝色“生效摘要”；保留思考另外附加橙色提示，不另设半覆盖状态。配有文字和替代链提示。颜色依据有效上下文计算，思考是否实际回传仍由 DSH 模型适配器决定。原生消息渲染器和内容保持正常，插件仅附加状态标签。
- **记忆助手（小 DSH）**：打开“记忆助手”页，点“打开 / 恢复助手”。独立原生 DSH 聊天、输入框、流式回复、工具执行、停止和历史；使用已有 provider 配置，不复制 API key。新助手继承目标会话所选模型，已有助手恢复自己的模型记录，无选择时使用默认模型。

编辑助手回复时可逐块编辑思考，默认保留未修改的思考、附件和工具块。需要时勾选 **同时清除本条旧思考**。旧思考可能由模型适配器回传，所以只改正文后仍可能与旧思考冲突。操作仅作用于本条已编辑消息，不改变 DSH 的正常思考回传。未改动块保留签名；改过的正文/思考不复用原内容签名，当前模型的 reasoning_content 等回传字段标记继续保留。改摘要不会自动改其他旧回复，需逐条编辑或移出上下文。

编辑框载入完整正文；Ctrl+Enter 保存、Esc 取消。“保存前检查”对照正文和逐块思考的修改前后内容；取消前不写盘。草稿固定使用打开编辑框时的 contentRevision，后台刷新不替换基线；冲突会拒绝保存并保留草稿，复制草稿后取消、重读核对。运行环境、技能目录与系统指令单独标记并折叠展示。

## 使用记忆工作台

1. 打开 **编辑器 → 记忆工作台 → 局部压缩**，从“合法压缩区间”快捷选择，或自定义起止位置，核对选区成员。区间外消息保留；系统/运行环境/技能目录、附件和工具调用不能混入此压缩选区。工具结果用独立裁剪操作。
2. 自己填写摘要并点击 **生成审核候选**，或点 **让助手起草此选区**，在助手的任务草稿中核对后点 **发送给助手起草**。草稿不会自动发送。回工作台检查候选前后及估算 tokens，再点 **应用此候选**。多个候选默认展开第一条，其余按需展开。
3. **找回原件** 支持正文和思考搜索、分页阅读全文。历史用户/助手正文可起草补回，作为新补充记忆加入上下文，不自动改写现有摘要。工具裁剪前快照显示“裁剪前快照”，选中同一次工具调用的结果后起草恢复。
4. **已处理候选 → 按字段恢复** 可以恢复该候选应用前的正文或思考；摘要恢复正文。恢复也先生成新候选，未选择的字段保留。此入口对应工作台候选快照；以前直接编辑器保存的历史版本仍在日志备份中，并未自动导入此恢复列表。

局部压缩按 DSH 原生 compaction 生命周期提交，原事件保留。工具结果在轮次结束后不能追加替换事件，因此使用独占写锁、完整日志校验及原子替换，只改变 content，调用编号、错误状态和附件保持原样；完整日志备份与工作台快照同时保留。工具裁剪是人工工作台能力，不扩大记忆助手读取工具结果的权限。

候选以会话为单位保存在 `DSH_HOME/session-editor/candidates`；不会因隐藏较早处理记录而删除恢复快照。每个会话最多 100 个待审候选，队列及快照总大小上限约 12 MB，达到上限会拒绝新增。token 数字是估算值；真正应用局部压缩还会通过当前 DSH 的估算检查是否缩短。候选期间目标内容变化会拒绝应用；不相关的新消息不自动使候选失效。

工作台后端与界面逻辑已经过自动化验证，并已包含在 Windows 安装包中；完整界面的真实点击和视觉验收尚未完成。验证范围见仓库中的 `docs/VALIDATION.md`。

常用入口为“有效上下文 / 生效摘要 / 记忆工作台 / 记忆助手”；覆盖关系、原始事件和手动同步移到“更多工具与使用说明”。同一会话切换页签保留已打开的编辑草稿及滚动视图；关闭编辑器或切换目标会话不会持久保存未提交草稿。历史检索按内容实际状态标记，生效摘要和当前消息提供编辑入口，归档原文提供承接摘要入口。

## 用模型操作记忆

记忆助手系统提示词独立存放于插件根目录的 **AGENT.md**，代码不再内嵌提示词正文。`{{TARGET_SESSION_ID}}` 在安装助手提示时替换为固定目标会话 ID，请保留该占位符。安装器及 npm 包均包含此文件；使用安装目录中的 AGENT.md，源码修改需要同步到安装目录。运行中的助手保持原提示；关闭后重新打开助手会重新读取文件，普通恢复会话也会重新安装提示，无需刷新网页。

在记忆助手中直接描述要求，例如“搜索与摘要矛盾的旧回复，先说明位置，再按我的要求修改”。助手可分页读取有效上下文和历史、搜索文字、读摘要、编辑正文与逐块思考、显式清除思考、编辑摘要、移出上下文。默认保留未指定修改的正文、思考、工具和附件。已被覆盖原文只读，修改承接它的有效摘要。助手仅有 9 个专用记忆工具，固定绑定当前目标，无 shell 或通用文件工具。

记忆助手的读写边界由代码控制：只提供目标用户/助手正文、思考、摘要，以及助手自身管理对话；不提供目标系统/开发者指令、自动运行环境、技能目录/调用、工具结果、请求头或原始流。附件和工具调用只显示受保护占位，修改时原样保留。历史读取、按猜测编号读取、搜索都经过相同白名单；完整日志仍参与版本比较。

写工具必须携带刚读取的 contentRevision，版本冲突或目标正在生成时拒绝写入。正文/摘要编辑自动备份；移出操作保留原始历史。成功修改后自动同步左侧及编辑器，“最近记忆操作结果”显示实际工具结果。关闭停止并释放助手，重新打开可恢复同一助手历史；“新建助手对话”保留旧历史并新建。编辑器内切换页签保留浏览器引用；关闭编辑器或切换目标才释放引用，不撤销已完成写入，也不自动停止服务端任务，需用“停止助手”或“关闭助手”。

助手作为独立普通 DSH 会话持久保存，可能出现在 DSH 会话列表。隔离助手使用 `session-editor-memory-v1-` 前缀，服务重启后由 agent/created 钩子重装专用工具、系统提示和自动注入过滤，直接从原生列表打开也受限制。旧前缀助手仅保留历史并拒绝续聊；从目标编辑器打开将创建新的隔离助手，不沿用旧管理上下文。原生模型选择器的部署默认副作用沿用 DSH 规则。

消息编辑会释放空闲会话的内存实例、取得独占写租约、校验完整日志，然后备份并原子替换文件。生成中的会话和仍持有子任务的会话不能编辑。其他已打开的标签页需刷新以重新读取历史。

## 安装

源码适配五个官方构建：DSH 0.1.7-rc.2、0.2.0-rc.1、0.2.0-rc.2、0.2.1-rc.1、0.2.1-rc.2；各版本实测层级见仓库可靠性验证。Node.js 至少为 24。安装器核对宿主文件 SHA256 及结构锚点；不同构建会拒绝安装，不尝试猜测性修改。

先停止目标 DSH 服务。解压发布 tgz（包含 package 目录），执行一次：

```powershell
node package/install.mjs --app "D:/path/to/dsh" --home "D:/path/to/dsh-home"
```

`--app` 是包含 lib/bin.js 的 **DSH 程序目录**，依赖按所选宿主实际模块解析路径定位，支持 npm 提升安装；`--home` 是该服务的 **DSH_HOME**。安装器结构化修改 YAML，兼容默认 `[]`。命令行直接调用只确认文件事务，不能代表网页已启动；Windows EXE 会进一步验证网页和插件健康。

`--check` 只读预检；`--defer-health` 提交后保留待验证事务，服务健康通过后执行 `--complete`。失败或进程中断时先停止目标服务，再执行同样 app/home 参数并加 `--recover` 回滚。若文件有第三方改动，会保留事务及备份并拒绝覆盖。同一宿主只能绑定一个活动安装数据目录。

适配修改 dsh-agent 和 dsh-agent-loop 的构建文件，增加“经原 Owner 释放空闲会话”的接口；另适配 dsh-api-session-controller 的客户端重载，成功重开后恢复可用状态。上下文组装、模型思考回传、工具调用与压缩算法沿用 DSH 原逻辑。宿主升级可能覆盖适配；升级后需安装兼容版本。

## 卸载恢复

停止 DSH 后，使用同一个发布包：

```powershell
node package/install.mjs --app "D:/path/to/dsh" --home "D:/path/to/dsh-home" --uninstall
```

恢复宿主原文件及安装前配置/插件；卸下的包保存在 DSH_HOME/.session-editor-transactions 的事务快照中。若安装后宿主或配置又有其他修改，拒绝覆盖。会话内容不会随卸载回滚；如需回滚消息，可使用对应的历史备份。旧 log-rewrite.mjs 仅保留 inspect 只读诊断；其直接写入、恢复及贪婪修复命令已禁用，所有会话改写须经过网页编辑器的原生写租约和完整校验。

当前版本不提供插入消息 GUI、所有历史备份的通用恢复浏览器或历史虚拟列表。候选审核及候选快照的字段恢复已提供。已被压缩的原文只读，通过生效摘要调整后续上下文。其他已打开的页面需自行同步或刷新。
