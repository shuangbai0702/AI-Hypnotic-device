# 安装与会话一致性改进计划

依据用户提供的服务器分析及本机调查，不将旧测试结果视为本次证据。只在本机新建隔离副本和独立端口测试；不对正式 DSH、3080 或既有开发服务执行安装、停止、启动或数据修改。服务器留作后续交叉验证。

1. 会话读写：重现多帧差异；按 Zstd 帧结构精确解码，严格 UTF-8/JSONL 解析，损坏数据拒绝写回；覆盖单帧、多帧、异常尾部、备份恢复及长日志。维护工具共用同一解码器。
2. 安装事务：结构化修改 YAML，覆盖原生默认 `[]`；准备产物、记录事务及备份、提交、故障恢复。启动失败回滚，重装保留自定义提示，卸载保护后续修改。区分文件提交和服务健康确认。
3. 自动发现：多来源发现 DSH、数据目录、端口及 Node；复用 DSH 使用的运行时，能力验证与有界重试。多个候选时提供选择，手工路径为高级兜底；可选下载隔离 Node 24，校验官方散列，不改全局 PATH。
4. 兼容性：获取五个发布版本的实际构建，比较生命周期及客户端接口；仅对验证过的适配/结构放行，不移除保护。调查原生释放扩展点，并记录已测与未测边界。
5. 本机验证：新增底层和故障注入测试、完整回归、新 DSH 默认安装/启动/重装/卸载、实际模型请求中编辑持续生效、再次压缩与重开。构建 EXE；能取得浏览器控制时做真实交互，否则单列未验收，不冒充点击验收。
6. 发布收口：审查差异、隐私及 Plan vs Actual；尚有阻断缺陷或必要验收未完成时不更新公开安装包。记录资源/性能证据，不把进程 Killed 擅自归因为 OOM。

## 0.4.2 更新与安装器界面增补

依据用户后续要求“新版覆盖旧版、旧版不能覆盖新版、安装器自动更新、不需要启动器、可爱二次元 GUI”，本轮范围如下，不改变上述隔离边界。

1. 在预检和持锁提交前检查语义版本，支持新版本升级及同版修复，损坏或冲突元数据拒绝写入；升级记录与代码同事务回滚，保留最初卸载基线。验证实际公开旧包对新记录的拒绝行为。
2. 图形安装器后台检查官方稳定发布，校验下载及文件清单后交接新版；离线和异常保留当前包可用。自动化入口保持指定包可重复执行，不自动替换版本。
3. 依据用户后续提供的图片，直接使用原图按比例裁切显示并采用蓝白界面，不重画角色，不新增常驻进程；核对实际窗口、离线重试、交接和关闭生命周期。
4. 执行语义版本/异常输入/回滚回归、Windows PowerShell 5.1 与 PowerShell 7 更新测试、隔离 EXE 安装矩阵及隐私差异检查。记录环境边界，不宣称所有机器和未知 DSH 构建可用。
