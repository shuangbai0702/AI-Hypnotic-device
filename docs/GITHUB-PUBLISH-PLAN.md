# GitHub 发布计划

1. 确认账号与删除授权，删除用户指定的三个旧个人仓库，并复查列表。
2. 按白名单整理插件、Windows 安装器、合成数据回归测试；排除运行数据、旧调试脚本、日志、抓包、个人路径及凭据。使用匿名化的提交邮箱。
3. 编写安装、功能、兼容范围、宿主改动、卸载及开发验证说明；运行回归、发布文件检查和安装器构建，检查最终 ZIP。
4. 创建新的私有项目仓库，推送经检查的初始提交，附上 Windows 发布包，并复查远端文件与发布附件。

验收与 Plan vs Actual 记录于 VALIDATION.md。该任务不对正在使用的 DSH 安装或重启，不改动本机聊天。
