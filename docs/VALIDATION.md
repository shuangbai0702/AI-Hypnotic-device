# 验证说明

本文件记录旧发布阶段的验证；本轮安装事务、多帧日志和五版本兼容测试见 [可靠性验证](RELIABILITY-VALIDATION.md)。不要用旧发布的 49 项结果替代当前源码的重新验证。

## 已有功能与安装验证

发布前开发阶段使用新的临时 DSH 和数据目录验证了 EXE 自动化入口的安装、启动、重复安装和卸载，包括中文及带空格路径。验证覆盖上下文编辑、摘要编辑、局部压缩、归档只读、候选恢复、工具裁剪、连续移出上下文及原生聊天 footer 投影。记忆助手使用本机 mock 模型走原生工具循环，不调用付费模型。

不兼容宿主和其他程序占用端口时拒绝安装；重装保留自定义 AGENT.md；卸载前检查后续宿主和配置改动。临时运行环境在验收后移除。

这些是先前开发验证，不能替代本次发布的重新检查。安装窗体按钮和 DSH 界面的真实点击、视觉验收尚未完成；mock 模型验证也不代表真实模型的理解质量。正式用户的 DSH 未用于安装实验。
