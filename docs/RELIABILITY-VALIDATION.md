## 计划偏移与边界

1. **仍需三个宿主适配点。** 调查过原生工厂/生命周期：网页创建的驻留 agent 没有满足编辑要求的公开闲置释放入口。保持由原所有者释放并重开，使用逐构建散列和锚点约束，没有通过删除检查扩大支持。后续原生接口改变需重新适配。
2. **旧离线写命令收敛为只读检查。** `log-rewrite.mjs` 原本的编辑、删除、插入、修复、恢复路径绕开原生写租约。为避免旁路写入，现明确拒绝这些命令；网页编辑能力保留。拒绝路径测试确认源文件不变。这是有意的维护接口兼容变化。
3. **首次原生 profile 初始化在受管文件事务之前。** 失败时回滚插件和宿主变更，但可能保留 DSH 自行生成的空白 profile/日志；不递归删除可能被其他程序使用的新目录。凭据文件不属于安装事务目标。
4. **自动发现有边界。** 扫描常用进程、PATH、npm/版本管理器及有限缓存目录，不遍历全部磁盘。其他进程的自定义环境不能可靠反推；已有安装记录优先，多候选由用户选择，高级项可校正。自定义启动参数不会被静默丢弃，安装器会保留进程并提示先手动关闭。
5. **环境限制没有改写为成功。** 当前计算机控制工具没有可用浏览器或应用表面；未验证安装器按钮、真实浏览器 DOM/视觉和普通双击启动。已验证 HTML/静态资源及原生 RPC，不能替代视觉验收。未连接服务器，未做 Linux 验收、真实账号接口验证或系统级断电/磁盘满测试。
6. **账户截图仅有状态解释。** 原生 DSH 可在本地有登录凭据、资料请求失败时显示“账号资料暂不可用”。安装/卸载测试的合成凭据未变化；没有对方日志，不能断言插件损坏认证，也不能保证其账户网络恢复。没有删除或重写真实凭据。
7. **发布计划按用户后续要求调整。** 初次收口时只提供本地候选包；后续依用户明确要求发布 0.3.1，保留旧版供追溯，并公开未验收边界。没有将旧版 47/49 或本轮 72/72 描述为全部发布验收完成；`Killed` 的原服务器原因也未确认为 OOM。

## 服务器网页报告后的续聊修复（2026-10-22，0.3.2）

用户随后提供了针对提交 `5503433`、DSH `0.2.1-rc.2` 的服务器真实网页报告：连续移出旧回复后再调用模型，轮次从 4 回退到 3，官方严格关系校验失败。这是发布阻断问题。上文五版本测试在移出后只验证历史与分页，没有再次调用模型，不能证明这条链路健康；原来的通过结果仍限于当时列出的覆盖范围。

本轮按用户新要求直接使用本机开发网页（3099），明确允许重启这个开发服务；正式 3080 不改动。原计划对既有开发服务的保护因此由本次明确授权调整。测试均在新建的合成会话中进行，不修补或删除用户已有聊天。

### 根因与修改

- 在开发网页复现了同一故障：正常第 1、2 轮，两个移出操作追加第 3、4 轮，实际续聊又写第 3 轮；日志可解码，但严格关系校验失败。故障测试日志原样留存。
- `lib/edit.js` 原来向驻留 Session 直接追加合成轮次，没有重建 agent loop 缓存的轮次。现在移出、插入及旧式追加编辑统一先由原生命周期 Owner 释放空闲 agent，再持有独占持久化写租约。用未注册的 detached Session 构造事件，写入前对原日志及完整候选日志执行官方严格关系校验。下一轮从新日志恢复 agent，避免旧缓存回写。
- 生成中、释放失败、版本冲突、已归档目标及损坏原日志均拒绝提交。没有已有助手消息模板时拒绝构造不完整助手事件；无 developer 模板时补齐原生消息身份。网页旧助手正文、思考的物理编辑能力保留。
- `lib/client.js` 移出后同步重开左侧；消息保存、摘要保存、候选应用和助手修改都在原生同步结束后刷新编辑器版本。实际网页操作另发现：同步重开可能追加恢复标记，先刷新编辑器会缓存旧 revision，紧接着移出就冲突。现在保持保存中状态直到同步结束，保留真正并发写入的冲突保护；退出中的旧视图不再刷新或回写。

## 默认启动目录与持久诊断修复（2026-10-22，未发布源码）

用户提供其他使用者截图：`edit_message` 返回 path 参数为 undefined，`propose_memory` 返回 DSH_HOME 未配置。代码确认两个入口均直接依赖环境变量，而原生 DSH 的默认数据目录不要求设置该变量。此前回归统一设置了 DSH_HOME，漏掉了原生默认启动这一条件。本次没有取得对方日志，因此确认的是同条件缺陷与本地修复，不宣称已经远程修好对方机器。

本轮实施依据为“先修复目录识别，再补齐持久日志、错误堆栈、脱敏导出与默认启动回归”。增加统一的运行目录解析：优先使用持久化服务实际 session root；标准 sessions 目录可推导数据目录，否则采用非空环境变量、安装记录、原生默认目录。编辑与备份、候选队列统一采用该结果，安装器新增 home 记录，兼容旧的仅有 app 的记录，不修改宿主环境变量。

日志覆盖插件启动、所有已注册插件路由、助手工具和前端网络/会话同步/下载失败。请求包含关联编号、状态、耗时；工具失败返回可对应日志的 diagnosticId。错误不保留任意原始 message，保留类别、代码及移除绝对目录的调用帧。日志按 2 MiB 文件、4 个归档轮转，最近 200 条有内存缓冲；写盘失败不改变已完成业务结果，状态和下载提示暴露失败代码。导出不拼接安装器输出或原生聊天日志，不上传外部服务。

## 原生窗口启动与交互验收完成（2026-10-23，未发布源码）
